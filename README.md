# BB STRIKE SD — 6vs6 サバゲー・バトル

> **お知らせ：今後は「BB STRIKE SD」を主流として開発・更新していきます。**
> これまでの「BB STRIKE」（4vs4・等身のキャラクター）は [v0.1.0](../../releases/tag/v0.1.0) からダウンロードできますが、新しい機能や修正は SD 版に入れていきます。

エアソフト（サバイバルゲーム）を題材にした、Windows 用の三人称シューティングゲームです。
BB弾を1発ずつ物理計算（空気抵抗・HOP・弾の重さ）し、ヒットされたら手を挙げて「ヒット！」とコールして自陣へ走って戻る、サバゲーらしいルールで遊べます。
SD 版は、ちびキャラ（SD）の兵士で 6vs6 を戦います。

## ダウンロード

[Releases](../../releases/latest) から `BBStrikeSD_Setup_<版>.exe` をダウンロードして実行してください。

- 管理者権限なしでインストールできます（自分だけ／全員を選べます）
- 「BB STRIKE」とは別のアプリとして入るので、両方を並べてインストールできます
- アンインストールは「設定 → アプリ」から
- 署名していないため、初回は Windows SmartScreen の警告が出ることがあります。「詳細情報」→「実行」で進めてください

## 動作環境

- Windows 10 / 11（64bit）
- DirectX 11 / 12 対応の GPU
- キーボード＋マウス、またはゲームパッド

## 遊び方

- **バトル**: Bot と 6vs6。マップ3種（荒野・森林・室内CQB）、昼・夜間戦
  - **フラッグ戦**: 中央付近の中立のフラッグ A・B・C を奪い合います。ボタンを押し切ったチームのものになり（取られても奪い返せます）、3つとも取ったチームの勝ち。時間切れならフラッグの多いほうの勝ちです
  - **殲滅戦** / **カウンター戦**
- **BBミサイル**: 8ヒットごとに1回要請できます。敵がいちばん多い所へ、300発の BB弾を撃ち込みます（ミサイルでのヒットは次の要請までのヒット数に数えません）
- **オンライン対戦**: 専用サーバーで自動マッチング、またはキーを使ったプライベート部屋。LAN 内でも遊べます
- **射撃練習場**: 銃・BB弾の重さ・HOP の違いを試せます
- **ロードアウト**: 銃10種類、BB弾の重さ、HOP、サイト（アイアン・ドット・3倍・6倍スコープ）、マガジン、衣装・ヘッドギア・顔・アイウェアなど
- **覗いたとき**: 一人称で銃を構え、スコープはレンズの中だけ拡大されます

| 操作 | キーボード＋マウス | ゲームパッド |
|---|---|---|
| 移動 / 視点 | WASD / マウス | 左スティック / 右スティック |
| 射撃 / ADS | 左クリック / 右クリック | RT / LT |
| ダッシュ / しゃがみ / ジャンプ | Shift / C・Ctrl / Space | L3 / B / A |
| 伏せ | Z・X | B 長押し |
| リロード | R | X |
| 投擲 | G・Q | RB |
| BBミサイル | M | LB |
| HOP 調整 | ホイール | 十字キー上下 |
| セレクター / ライト | B / L | — |
| フラッグ | F・E 長押し | Y |
| チームへの命令 | 1〜4 | — |
| スコア / ポーズ | Tab / Esc | — |

設定画面の「視点のなめらかさ」で、視点の動きのなめらかさ（なし・弱・ふつう・強）を選べます。

## 使用素材

- キャラクター: AI 生成の 3D モデルを元に作成（リグ・アニメーションは Mixamo）
- 銃のモデル: 作者が用意したモデル、Low Poly Guns
- 樹木: Handpainted Forest Pack
- その他のモデル・テクスチャ・効果音・BGM はゲーム内で生成しています。音声コールは Windows の日本語音声合成で作成しています

このリポジトリにはゲームのソースコードは含まれていません。
