# BB STRIKE — 4vs4 サバゲー・バトル

エアソフト（サバイバルゲーム）を題材にした、Windows 用の三人称シューティングゲームです。
BB弾を1発ずつ物理計算（空気抵抗・HOP・弾の重さ）し、ヒットされたら手を挙げて「ヒット！」とコールして自陣へ戻る、サバゲーらしいルールで遊べます。

## ダウンロード

[Releases](../../releases/latest) から `BBStrike_Setup_<版>.exe` をダウンロードして実行してください。

- 管理者権限なしでインストールできます（自分だけ／全員を選べます）
- アンインストールは「設定 → アプリ」から
- 署名していないため、初回は Windows SmartScreen の警告が出ることがあります。「詳細情報」→「実行」で進めてください

## 動作環境

- Windows 10 / 11（64bit）
- DirectX 11 / 12 対応の GPU
- キーボード＋マウス、またはゲームパッド

## 遊び方

- **バトル**: Bot と 4vs4。フラッグ戦 / 殲滅戦 / カウンター戦、昼・夜間戦、マップ3種（荒野・森林・室内CQB）
- **オンライン対戦**: 専用サーバーで自動マッチング、またはキーを使ったプライベート部屋。LAN 内でも遊べます
- **射撃練習場**: 銃・BB弾の重さ・HOP の違いを試せます
- **ロードアウト**: 銃7種類、BB弾の重さ、HOP、サイト、マガジン、衣装・ヘッドギアなど

| 操作 | キーボード＋マウス | ゲームパッド |
|---|---|---|
| 移動 / 視点 | WASD / マウス | 左スティック / 右スティック |
| 射撃 / ADS | 左クリック / 右クリック | RT / LT |
| ダッシュ / しゃがみ / ジャンプ | Shift / C・Ctrl / Space | L3 / B / A |
| 伏せ | Z・X | B 長押し |
| リロード | R | X |
| 投擲 | G・Q | RB |
| HOP 調整 | ホイール | 十字キー上下 |
| セレクター / ライト | B / L | — |
| フラッグ | F・E 長押し | Y |
| スコア / ポーズ | Tab / Esc | — |

- キャラクター: Survivalist
